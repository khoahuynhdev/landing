Privacy policy

Last updated: 2026-10-07

khoahuynh.dev is a static website. It has no user accounts, no forms and no scripts. It does not collect personal data from visitors.

Cookies and tracking

This site sets no cookies. It uses no analytics, no advertising tools, no tracking pixels and no third-party fonts or content networks. Every page loads only from this domain.

Server logs

The site is hosted on GitHub Pages. The host may keep standard server access logs, such as IP address, time of request and browser user agent, as part of running its service. I do not have access to or use these logs for tracking. See the GitHub Privacy Statement for how GitHub handles this data.

Email

If you write to me, I receive your email address and the content of your message. I use it only to reply to you and do not share it with others.

Questions

For any question about this policy, write to hello@khoahuynh.dev.
